# lobeai 管理员接口交付说明（登录 + 调用）

> 本文档面向**对接开发方**，说明管理员接口的两种调用方式：
> 方式一（推荐）：先登录换取 token，再带 token 调用各管理接口。
> 方式二（兼容）：沿用旧方式，请求体直接携带管理员账密。
>
> 变更日期：2026-08-03

---

## 0. 认证方式总览

| 调用方式 | 何时使用 | 凭证 | 安全级别 |
|---|---|---|---|
| 方式一（token） | 新对接 / 建议一律使用 | 登录接口换取的 token，随请求头携带 | 高：账密只在登录时出现一次 |
| 方式二（账密） | 旧对接方未升级前的兼容路径 | 请求体直接携带管理员账密 | 低：每次调用都透传账密 |

> 两种方式能力等价，均调用同一批管理员接口。token 有效期内可反复使用。

---

## 1. 方式一（推荐）：登录换取 token

### 1.1 管理员登录

```
POST /api/admin/login
Content-Type: application/json
```

请求体：

```json
{
  "username": "管理员用户名",
  "password": "管理员密码"
}
```

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `username` | string | 是 | 管理员用户名 |
| `password` | string | 是 | 管理员密码 |

### 1.2 登录响应

```json
{
  "success": true,
  "data": {
    "token": "lq3mHn...（随机串）",
    "token_type": "Bearer",
    "expires_at": 1754210000,
    "expires_in": 86400
  }
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| `data.token` | string | 访问令牌，有效期 24 小时 |
| `data.token_type` | string | 固定 `"Bearer"`，调用时作为认证类型 |
| `data.expires_at` | number | 过期时间（Unix 秒） |
| `data.expires_in` | number | 剩余有效秒数，恒为 86400 |

### 1.3 token 使用方式

后续调用各管理员接口时，请求头携带：

```
Authorization: Bearer <token>
```

token 也可放在请求体中（与请求头二选一，请求头优先）：

```json
{
  "token": "<token>",
  ...其他业务字段
}
```

### 1.4 边界行为

| 场景 | 表现 |
|---|---|
| token 有效期内 | 正常调用 |
| token 过期 | 返回 `401`，需重新调用登录接口换取新 token |
| 登录失败（账密错误） | 返回 `401`，`message` 提示登录失败 |
| 进程重启后 token 失效 | 返回 `401`，需重新登录（token 保存在服务内存） |

---

## 2. 方式二（兼容）：请求体直接携带账密

不登录，直接在各管理接口请求体中携带管理员账密：

```json
{
  "username": "管理员用户名",
  "password": "管理员密码",
  ...其他业务字段
}
```

> 该方式为兼容旧对接方保留，建议新对接方统一走方式一。

---

## 3. 管理员接口清单

以下接口同时支持上述两种认证方式：

| 接口 | 方法 | 用途 |
|---|---|---|
| `/api/admin/login` | POST | 登录换取 token（仅方式一入口，无需认证） |
| `/api/admin/generate-activation-codes` | POST | 批量生成激活码 |
| `/api/admin/batch-create-tokens` | POST | 批量创建 NewAPI 令牌 |
| `/api/admin/openrouter/models` | POST | 获取 OpenRouter 模型列表 |
| `/api/admin/openrouter/search` | POST | 搜索 OpenRouter 模型 |
| `/api/admin/activation-codes/stats` | POST | 激活码统计信息 |
| `/api/admin/usage-summary` | POST | 平台套餐用量统计 |
| `/api/admin/price` | POST | 价格查询页面 |
| `/api/admin/text` | POST | 更新文本内容 |

> 除 `/api/admin/login` 外，其余接口的业务请求体、响应结构均与之前完全一致，本次变更仅涉及认证方式，不改变业务数据契约。

## 4. 调用示例

### 示例一：登录 + 查询用量统计（推荐方式）

```bash
# 1. 登录换取 token
TOKEN=$(curl -s -X POST http://<host>:25141/api/admin/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"xxx"}' | jq -r '.data.token')

# 2. 带 token 调用统计接口
curl -X POST http://<host>:25141/api/admin/usage-summary \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"granularity":"month"}'
```

### 示例二：沿用账密（兼容方式）

```bash
curl -X POST http://<host>:25141/api/admin/usage-summary \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"xxx","granularity":"month"}'
```

## 5. 常见错误码

| HTTP 状态 | message | 说明 |
|---|---|---|
| 401 | 登录失败 / token invalid or expired / 需要认证 | 凭证缺失、错误或过期 |
| 400 | 参数校验错误 | 业务字段不合法 |
| 403 | 权限不足 | 非管理员（方式二账密不是管理员） |
| 500 | 管理员会话不可用 | 内部共享会话异常，请联系平台方 |
