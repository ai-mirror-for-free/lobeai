# lobeai 对外接口文档（接口变更说明）

> 本文档面向**对接开发方**，说明 lobeai 对外接口的变更与当前契约。
> 近期变更：2026-08-02

---

## 1. 充值/额度聚合接口 — update-user-quota

返回用户在各套餐下的额度情况，统一人民币计价，按套餐类型打包为列表，便于后续扩展新套餐。

> **背景**：旧的多套餐按月付费体系已下线，当前仅保留 **claude code** 套餐（预付费 / 按量）。

### 1.1 请求

```
POST /api/update-user-quota
Content-Type: application/json
```

请求体：

```json
{
  "username": "张三",
  "email": "user@x.com"
}
```

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `username` | string | 是 | 用户名。当前**不参与计算**，仅保留字段 |
| `email` | string | 是 | 用户邮箱，格式需合法（EmailStr 校验）。**唯一判定键** |

### 1.2 响应

额度按套餐类型打包为 **`plans` 列表**（未来新增套餐时通知对接方追加一项）。

```json
{
  "email": "user@x.com",
  "currency": "CNY",
  "plans": [
    {
      "type": "claude code",
      "balance": 12.34,
      "total_recharged": 50.00,
      "unlimited": false,
      "has_key": true
    }
  ]
}
```

#### 字段说明

| 字段 | 类型 | 说明 |
|---|---|---|
| `email` | string | 用户邮箱 |
| `currency` | string | 币种，固定 `"CNY"`（人民币口径） |
| `plans` | array | 套餐额度列表，每项一个套餐 |
| `plans[].type` | string | 套餐类型，当前仅 `"claude code"` |
| `plans[].balance` | number | **剩余可用余额 ¥** |
| `plans[].total_recharged` | number | **该套餐累计充值 ¥** |
| `plans[].unlimited` | bool | 是否无限额度。为 `true` 时 `balance` 恒为 `0.0`，**以本标志为准** |
| `plans[].has_key` | bool | 该用户该套餐是否已开通（存在可用额度账户） |

### 1.3 边界行为

| 场景 | 表现 |
|---|---|
| 用户未开通该套餐 | `has_key: false`，`balance: 0.0` |
| 用户为无限额度 | `balance: 0.0` + `unlimited: true`（展示方应显示「无限」） |
| 额度数据暂不可用 / 未开通 | 优雅返回 `has_key: false`、`balance: 0.0`，**不返回错误** |
| 汇率数据暂不可用 | 金额按 `0.0` 处理，不影响接口可用性 |
| 未知的套餐 `type` | 返回全 0 占位记录，接口不报错 |

## 2. 管理员激活码统计 — activation-codes/stats

管理员查询激活码批次统计（按套餐 + 有效期 + 面额分组）。**本次变更：每个批次新增人民币面额 `quota_rmb` 字段**，原 `quota`（额度）字段保留不变。

### 2.1 请求

```
POST /api/admin/activation-codes/stats
```

> 需要管理员认证（管理员账号密码）。

### 2.2 响应

**变更前**：
```json
{
  "plan_level": "claude code",
  "days": 0,
  "quota": 737463,
  "total": 4,
  "used": 4,
  "available": 0
}
```

**变更后**（新增 `quota_rmb`）：
```json
{
  "plan_level": "claude code",
  "days": 0,
  "quota": 737463,
  "quota_rmb": 9.99,
  "total": 4,
  "used": 4,
  "available": 0
}
```

顶层另有 `summary` 汇总（`total` / `used` / `available` 数量），本次不变。

#### 字段说明

| 字段 | 类型 | 说明 |
|---|---|---|
| `plan_level` | string | 套餐类型 |
| `days` | number | 有效期（天），`0` 表示永久有效 |
| `quota` | number | 该批次激活码的额度 |
| `quota_rmb` | number | **该批次激活码的人民币面额 ¥（本次新增）** |
| `total` | number | 该批次激活码总数 |
| `used` | number | 已使用数 |
| `available` | number | 可用数（= total - used） |

### 2.3 对接方注意

- 展示人民币面额时取 **`quota_rmb`**；展示额度原值用 `quota`。
- 若接口部署的是老版本（尚无 `quota_rmb` 字段），前端应做容错：字段缺失时回退显示 `quota`。
